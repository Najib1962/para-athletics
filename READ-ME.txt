-------------------

Nothing goes in the main folder. server.js untouched, so your password
is safe this time.

Also in this folder: Athlete_Entry_Template.xlsx - the spreadsheet to
send to team managers. That is not part of the app; keep it wherever
suits you.


1. THE IMPORT NOW READS THE HEADING ROW
---------------------------------------
Columns can be in any order. These headings are recognised:

    Reg Num | Name | Club/Team | Gender | Year of Birth | Class |
    Event 1 | Event 2 | Event 3 | Event 4

Only Name and Class are required.

Each event goes in its OWN column and is named as a plain discipline -
"Shot Put", not "Mens Shot Put F32-34". The app finds the right event
from the athlete's class and gender, so team managers never need to know
how you have named things.

Tested: a sheet saying "Shot Put" found "Mens Shot Put F32-34", and a
woman's "100m" found "Womens 100m T37" rather than the men's race.

Year of Birth sets the age category on its own - under 20 is Youth.

Your OLD format still imports, so anything you already have keeps
working: Name, Class, Sex, Bib, Club, Events.


2. ADD ONE ATHLETE
------------------
A new box on the same page: Name, Class, Gender, Year of birth, Bib,
Club. For a late entry, where a whole spreadsheet would be overkill.
It tells you whether the athlete came out Youth or Open.

This answers your question about where to enter the age group - there
was no add-athlete form at all before, only the import.
