CHANGE 10 - SET THE AGE GROUP AS YOU ADD ATHLETES
=================================================

ONE FILE
--------
Into  Desktop\para-athletics\public\
    entries.html      replace

Nothing goes in the main folder. server.js is unchanged.


WHAT IS NEW
-----------
On the Entries page, next to the athlete picker there is now a small
box saying Open or Youth. Choose it and press Add Athlete. That is all.

When you pick an athlete, the box shows the group they already have, so
you only change it when it is actually wrong.

Athletes already marked Youth show as "Ahmed (T37) . Youth" in the
picker, so you can see at a glance.

Each athlete in the list below now shows an OPEN or YOUTH badge, with a
small "change" link beside it if you need to correct one afterwards -
no need to remove and re-add them.


THE AGE GROUP BELONGS TO THE ATHLETE
------------------------------------
As you asked: it is set once and applies in every event that athlete
enters. Their age does not change between events.

Where a single event holds both groups, the two are ranked separately -
each with its own first, second and third, and its own medals.


TESTED BEFORE SENDING
---------------------
The selector appears, offering Open and Youth.
Picking an athlete shows their current group.
Choosing Youth and pressing Add: the server recorded ageGroup "youth",
and the athlete was entered in the event.

A mixed event then ranked as:
    rank 1  Bilal (Open)    11.80  ->  900 points
    rank 2  Karim (Open)    12.40  ->  718 points
    rank 1  Ahmed (Youth)   13.20  ->  998 points

An event where everyone is the same group: no labels added, unchanged.
Typing marks, corrections, deleting, the login and the page lock: all
still work.
