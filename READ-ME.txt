HOW YOU WILL USE IT
-------------------
Open this one address:

    https://para-athletics.onrender.com/login.html

It asks for the password. Type it once, and you are taken to the admin
panel. Every admin page then works for the next 12 hours without the
password in the address - including when you click between them.

No more ?password=admin123 on the end of every address.

Old bookmarks with ?password=admin123 still work, so nothing you have
saved will break.


WHAT WAS WRONG WITH THE OLD LOGIN PAGE
--------------------------------------
It checked the password inside the page itself, against the word
admin123 written into the file. Anyone could read it by viewing the
page source. And changing the password on the server had no effect,
because the page never asked the server anything.

Now the server decides.


HONEST LIMITATION - PLEASE READ
-------------------------------
This gives you a proper login screen, but it does not yet lock the
admin pages away from strangers.

Someone who knows the address can still OPEN admin.html and use it,
because the password is also written inside admin.html, entries.html
and athletes.html - the same way it used to be inside login.html.

Removing it from those three pages is the change that would make the
login really mean something. Ask for it when you want it and I will
send it on its own.


TESTED BEFORE SENDING
---------------------
Wrong password         refused, nothing remembered
Correct password       accepted, browser remembered
Moving between admin pages afterwards, no password in the address:
                       admin, entries, athletes all work
A stranger with no login saving a mark:   refused
Old ?password= bookmarks:                 still work
Public pages:                             unaffected
Typing three marks and saving:            all three kept
