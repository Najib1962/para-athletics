WHAT WAS MISSING
----------------
Nineteen pages in your app DISPLAY the competition name - the public
schedule, the live results, the medal table, the printed start lists,
the booklet, all five display screens. But no page could SET it.

So the name has been whatever it was first created as, and there was no
way to change it. My guide told you to enter it on the Admin page. That
was wrong; I described the app from how it behaves rather than checking.


THE NEW PAGE
------------
Log in, then open:

    https://para-athletics.onrender.com/competition.html

There is also a link in the row along the top of the Admin page:
Competition Details.

    Competition name        appears everywhere
    Venue, City, Country    printed on start lists and results
    First day, Last day     printed on start lists and results
    Organiser, Contact      shown in the booklet
    Notes                   anything teams should know

At the foot of the page a white box shows exactly how the heading will
look on a printed sheet, before you save.


WHEN TO USE IT
--------------
Once, before each competition. Set it and forget it.


TESTED BEFORE SENDING
---------------------
Saved a full set of details from the page, then opened a printed start
list. The heading read:

    Sharjah Para Athletics Open 2026
    Venue  = Sharjah Sports Stadium, Sharjah
    Date   = 2026-11-05

The page is locked to strangers and opens once logged in.
