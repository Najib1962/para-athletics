WHERE THE FORM WAS
------------------
It was always there - the second card down on the Admin page, called
"Add Event". What made it hard to recognise is the class picker: a tall
scrolling list needing Ctrl+click to choose more than one. That does not
look like a set of choices, so the form did not read as a form.


WHAT IT LOOKS LIKE NOW
----------------------
The classes are tick boxes. Click the ones you want. A line underneath
tells you what you have built:

    one class    -> ranked on the performance itself
    two or more  -> combined, ranked on official Raza points

Classes with no points published for the discipline you have chosen are
greyed out. Choose Shot Put and T11, T45, T47, F31 and F51 fade, because
World Para Athletics publishes no shot put scores for them. You can no
longer build an event whose athletes would score nothing.

The class list is corrected too: F45 is gone - it is not in the WPA
tables - and T71, which was missing, is back. 55 classes in all.


HOW TO ADD AN EVENT
-------------------
1. Log in, open Admin
2. Second card down: Add Event
3. Event Name - write it as you would on paper, "Mens Shot Put F32-34"
4. Discipline, Gender, Day
5. Tick the classes
6. Press Add Event

The name is yours to choose. The import finds events by discipline and
class, not by name, so team managers never have to match your wording.
