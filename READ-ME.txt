WHAT CHANGES
------------
Until now anyone who knew the address could open your admin pages. The
password is written inside admin.html, entries.html and athletes.html,
so a stranger reading the page source could use them.

These pages now require a login. Anyone without one is sent to the
login page:

    admin.html
    entries.html
    athletes.html
    startlist-referee.html
    startlists-results.html
    startlists-export.html
    reset-data.html

Everything else stays open to the public as before.

No page files needed editing. The password written inside those pages
no longer matters - the server checks it, finds it does not match yours,
and falls back to your login instead.


BEFORE YOU PUSH - SET YOUR PASSWORD
-----------------------------------
1. Open server.js in Notepad
2. Ctrl+F and search for   ADMIN_PASSWORD
3. You will find:

       const ADMIN_PASSWORD = 'admin123';

4. Put your own password back between the quotes
5. Save
