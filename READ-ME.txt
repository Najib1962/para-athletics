CHANGE 5 - PUBLIC PAGES REFRESH THEMSELVES
==========================================

ONE FILE
--------
Into  Desktop\para-athletics\
    server.js       replace

Nothing else changes. No page files are edited.


WHAT IT DOES
------------
Your public pages already refreshed on a timer, but a slow one - between
15 and 60 seconds depending on the page. So a result could sit unseen on
a scoreboard for a minute.

They now notice a change within about 3 seconds.

You do not need to edit any page. The server adds a small piece of code
to each public page as it is sent.


WHICH PAGES
-----------
Refresh by themselves:
    the schedule (home page), live, medals, event, mobile,
    athletes-public, result-booklet, schedule,
    and all five display screens

Deliberately NOT, so nothing reloads while you are typing:
    admin, entries, athletes, login, reset-data,
    startlist-referee, startlists-results, startlists-export,
    team-entry


HOW IT WORKS
------------
The server keeps a number that changes whenever anything is saved. Each
public page checks that number every 3 seconds - a very small request -
and only reloads its data when the number has moved. Nothing is sent
between changes.


TESTED BEFORE SENDING
---------------------
Every public page receives the refresh code.
Every page where marks are typed does not.
The number changes when a result is saved.
The results-entry page was re-checked for typing: three marks entered
one after another, all three stayed on screen, all three saved.
Deleting entries, correcting marks and the points all still work.


INSTALL
-------
cd Desktop\para-athletics
git add .
git commit -m "Public pages refresh themselves"
git push

Wait 2 to 5 minutes.


THEN TEST
---------
Open live.html in one browser tab and the results entry page in another.
Pick the same event in both.

Enter a mark and press Save. Then look at the first tab WITHOUT
refreshing it. The result should appear within a few seconds.


A NOTE ON THE FREE PLAN
-----------------------
Render puts the site to sleep after 15 minutes with no visitors, and the
first page after that can take up to a minute to appear. With a display
page left open, the 3-second check keeps the site awake, so this should
stop happening during a competition.
