WHAT WAS WRONG
--------------
My mistake. The box was saving on every keystroke. Typing 2010 was read
as the year 2, then 20, then 201 - each one a complete date as far as
the browser was concerned - and the row redrew underneath you while you
were still typing.

It was the same error I made with the marks, and I am sorry for
repeating it.


WHAT IT DOES NOW
----------------
Nothing is saved until you leave the box, or press Enter. Type all four
digits in peace.

Just the YEAR is enough:

    2010            <- easiest, and all the rule needs
    15/03/2010      <- a full date, if you want it on the start lists
    2010-03-15      <- also accepted

Anything it cannot read is refused with a message, and the box goes
back to what it held before, so a mistyped entry never gets saved.
A year outside 1920 to this year is refused as well.


TESTED BEFORE SENDING
---------------------
Typed 2010 one digit at a time:

    box shows "2"      server holds nothing
    box shows "20"     server holds nothing
    box shows "201"    server holds nothing
    box shows "2010"   server holds nothing
    left the box  ->   server holds 2010, badge turned YOUTH

A bare year and a full date score identically:
    born 2010        Youth   998 points
    born 2007-12-31  Youth   998 points
    born 2006        Open    430 points

The printed start lists show whichever you entered, with Youth or Open
beneath it.
