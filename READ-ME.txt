MARKS DISAPPEARING WHILE YOU TYPE
=================================

MY MISTAKE, AND I AM SORRY
--------------------------
When I moved the points calculation off those two pages and onto the
server, I left something behind that broke result entry.

As you type a mark, the page works out the points. It now has to ask
the server for them, and the server takes a moment to answer. My code
handled that badly: when the answer arrived, it rebuilt the whole
results table from the server.

Anything you had typed but not yet saved was wiped in that rebuild.
So marks vanished as you entered them.


WHAT IT DOES NOW
----------------
Only the points figure is updated - the single number in that one row.
Nothing else on the page is touched, so what you are typing stays
exactly where it is.

While the server is answering, the points column briefly shows a dash,
then the figure appears. Your mark never moves.
