🖨️ Printable Start Lists

Blank sheets for the referees, filled in with the athletes already entered in the app. Track and field events each use their own layout.
Results are left empty to be written in by hand.

Printing is set to A4 landscape, one event per page. In the print box choose Save as PDF if you want a file rather than paper.
Every sheet carries a few extra blank lines for late entries.
