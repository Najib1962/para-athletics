📥 Import Athletes with Events

In Excel select your rows including the heading row, copy, and paste below. The columns can be in any order — the headings are read.

Reg Num   Name   Club/Team   Gender   Year of Birth   Class   Event 1   Event 2   Event 3   Event 4

Only Name and Class are required. Each event goes in its own column, named as a discipline — "Shot Put", not "Mens Shot Put F32-34". The right event is found from the athlete's class and gender.
Year of Birth sets the age category on its own: under 20 is Youth. Four digits, such as 2010.

➕ Add One Athlete

For a late entry, when a whole spreadsheet would be overkill.

The year of birth decides Youth or Open by itself — under 20 is Youth. Leave it empty and the athlete counts as Open until you set it.
